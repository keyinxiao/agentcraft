The free skill: systematic-debugging

Your agent stops guess-patching. The skill enforces four phases with a standing rule: no code changes until the failure reproduces on demand — then binary-search the causal chain, fix the violated invariant (not the symptom), and ship the fix with the regression test that failed first. Intermittent bugs get hunted: state, timing, environment.

All 8 skills in the full pack

test-driven-development

RED-GREEN-REFACTOR on every behavior change. One test per cycle, mocks only at real boundaries, every bug fix ships with the regression test that failed first.

systematic-debugging

Reproduce → isolate → fix the cause → verify. No code changes until the failure is understood. Intermittent = clue, not noise.

code-review

Six passes: concrete edge values, security quick pass, test effectiveness ("which test fails if this breaks?"), blast radius, readability.

legacy-onboarding

Map before edit: entry points, one request traced end-to-end, load-bearing weirdness, green/yellow/red safe-change zones.

refactoring-safely

Behavior-preserving by definition: green-only, one transformation per step, parallel-change signatures, never mixes with feature commits.

security-audit

Entry points and trust boundaries, injection sweep, per-route auth, secrets scan with rotation rule. Evidence-only findings.

api-design

Resources before endpoints, mandatory pagination, one error envelope, additive-only evolution. Money is integers; time is UTC ISO.

write-docs

Every command executed before it is documented; claims linked to code; docs tested on clean clones.
